# ActiveDot

本项目主要是为了“欺骗”远程控制软件（网易UU远程、Parsec、向日葵等）的静态画面检测：只要画面有持续变化，动态编码器就不会降帧率，避免突然操作时的卡顿，降低操作画面延迟，使得鼠标观感跟手性更好。

这是一个轻量级的 Windows 桌面工具。它在屏幕角落显示一个极小的、持续在亮/暗两种状态间翻转的半透明小块，从而使得远程控制软件的静态画面检测认为画面在持续变化，避免降帧率。

若您在远程控制软件中遇到突然操作时鼠标延迟、操作不跟手等问题，可以尝试使用本工具。

## 编译环境

- .NET SDK 6.0 或更高

- 目标框架：`net8.0-windows`

- 无需任何第三方 NuGet 包，纯 .NET SDK + 系统 API

- Windows 10 / Windows 11

## 如何编译

```powershell
cd ActiveDot
dotnet build -c Release
```

编译产物：

```
ActiveDot\bin\Release\net8.0-windows\ActiveDot.exe
```

程序为**便携式**：配置文件 `config.json` 与 `ActiveDot.exe` 放在同一目录，无需安装、无需管理权限。

## 运行说明

下载Release中的压缩包，解压后直接运行 `ActiveDot.exe` 即可。

- 自动最小化到**系统托盘**（通知区域），默认在屏幕角落显示闪烁小窗。

- 闪烁块为**极小的半透明置顶窗口**，一帧半透明白、一帧半透明黑，利用视觉暂留看起来不黑也不白，明暗差异刚好能被静态检测捕获。

- **双击托盘图标**打开设置面板。

## 系统托盘右键菜单

| 菜单项 | 功能 |
| - | - |
| 显示设置 | 打开设置面板 |
| 启用闪烁 / 禁用闪烁 | 一键切换开关（当前状态动态显示） |
| 退出 | 退出程序 |

## 设置面板

面板内的“保存并应用”会应用尺寸与绝对坐标；“关闭”只隐藏面板，不退出程序（托盘图标仍在）。“启用闪烁、亮度变化、闪烁频率、可拖动模式、开机自启”等均实时生效并自动保存。

| 配置项 | 说明 |
| - | - |
| 启用闪烁 | 开启/停止小块明暗交替闪烁 |
| 尺寸 | 宽 × 高（范围 1–64），默认 2×2 |
| X / Y 坐标 | 输入像素坐标定位；点击输入框会自动退出可拖动模式 |
| 可拖动模式 | 勾选后可直接拖拽闪烁块定位，拖动会被限制在显示器四边内 |
| 亮度变化 | 滑动控制明暗差异（1–10）。值越大闪烁越明显，越小越轻微 |
| 闪烁频率 | 每秒明暗翻转次数（1–100，可手动输入，默认 30）。受显示器刷新率、系统与显卡性能上限制约，越低越省 GPU |
| 开机自启 | 注册/取消当前用户自启动（无需管理员） |

## 默认配置

首次运行（或删掉 config.json 后）使用以下默认值，写入同目录 `config.json`：

| 配置 | 默认 |
| - | - |
| 尺寸 | 2 × 2 px |
| 位置 | 屏幕左上角（百分比定位，可跨分辨率） |
| 亮度变化 | 1（最轻微）|
| 闪烁频率 | 30 Hz |
| 开机自启 | 关 |

## 核心实现要点

- **渲染与限频**：用 `CompositionTarget.Rendering` 与显示器垂直同步（vsync）对齐；再按"闪烁频率"（1–100）限频翻转亮/暗状态，其余 vsync 直接返回，DWM 不每帧合成，显著降低 GPU 占用。

- **半透明黑白交替**：亮帧暗帧交替，各带一层真实 alpha（复用同一画刷，只改颜色，避免每帧分配对象引发 GC）。两帧平均色贴近窗口下方背景，视觉上不黑也不白；亮度差足以被静态检测捕捉。

- **窗口样式**：无边框、极小的 `Topmost` 置顶窗口；`ShowInTaskbar=False`、`WS_EX_TOOLWINDOW`（不出现于 Alt+Tab）、`WS_EX_NOACTIVATE`（不抢焦点）；渲染循环里**每秒置顶一次**，防止被任务栏或其它置顶窗口盖住。

- **点击穿透**：默认开启——设置 `WS_EX_TRANSPARENT` 并配合 `WM_NCHITTEST` 返回 `HTTRANSPARENT` 兜底，鼠标直接穿透到下层。进入可拖动模式时自动临时关闭，退出后自动恢复。下方 AppConfig 与代码注释可见，点击穿透为固定行为，无独立开关。

- **拖动限位**：拖动不用系统拖拽，而是手工跟踪鼠标位移并用 `Math.Clamp` 把窗口钳制在显示器四边内，确保闪烁块始终完整可见。

- **单实例**：命名 Mutex 保证同一时间只有一个程序实例。

- **图标**：图标以多尺寸（16–256px）嵌入 exe（`ApplicationIcon`），另复制一份 `ActiveDot.ico` 到 exe 同目录供托盘/设置窗口加载；也可直接替换该 `.ico` 文件换图标。
